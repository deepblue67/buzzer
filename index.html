Comment ça marche ?
  1. Le maître du jeu crée une partie sur son téléphone : un code et un QR code s’affichent.
  2. Les joueurs scannent, choisissent prénom, avatar, couleur et son de buzzer.
  3. Le maître du jeu pose sa question, les joueurs buzzent. La file d’arrivée s’affiche partout.
  4. Il valide les réponses dans l’ordre : ❌ on passe au suivant, ✅ +1 point et question suivante.

Équitable : chaque téléphone synchronise son horloge avec celle du maître du jeu, et c’est l’heure réelle de l’appui qui compte, pas la vitesse du réseau.

🧪 Mode local : Supabase n’est pas configuré (js/config.js). Les onglets de ce navigateur jouent entre eux.
